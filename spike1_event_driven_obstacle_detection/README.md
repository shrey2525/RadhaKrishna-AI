# Spike 1 — Event-Driven Obstacle Detection

A reproducible first spike for testing whether a spiking neural network can process sparse temporal events without first converting them into dense video frames.

## Hypothesis

A spiking neural network can process sparse visual events directly while retaining near-baseline classification fidelity and reducing active computation.

This first version is deliberately synthetic. It is a research spike, **not a claim of hardware-level energy savings**.

## Compared systems

1. **ANN baseline:** sparse events -> dense event histogram -> small MLP.
2. **Brian2 SNN:** individual events -> LIF network -> spike-based readout.

Both use the same generated event sequences.

## Metrics

- accuracy, precision, recall, F1
- simulated decision latency
- event count
- SNN spike activity
- activity reduction proxy

### Important interpretation

Brian2 is a simulator. This project does **not** claim actual 10x CPU latency or energy reduction. The activity metrics test whether the SNN exploits sparse computation. Actual hardware measurements belong in a later neuromorphic phase.

## Experiment

Each sample is a sparse stream of events `(x, y, timestamp, polarity)` generated by a moving object.

- Class 0: object moves left -> right.
- Class 1: object moves right -> left.

The task therefore contains temporal information. The ANN receives a dense spatial event histogram. The SNN receives events sequentially.
